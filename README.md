# Кошачий беспредел

Браузерная 2D-игра: кот остаётся один в квартире и за 2 минуты 50 секунд устраивает хаос — роняет вещи с полок, дерёт обои, лазает по шторам и шкафам и доводит соседей до белого каления.

**Играть:** https://logunovaleksey-prog.github.io/cat-chaos/

## Коты
1. **Персик** — рыжий толстячок.
2. **Барсик** — коричневый, прыгает в 1,5 раза выше.
3. **Бродяга** — худой бездомный кот, влез через форточку.

## Управление
- ← → / A D — бегать, Пробел — прыжок
- ↑ / W — лезть по шторам и шкафам, ↓ / S — спрыгнуть
- J / Z — лапа (столкнуть предмет), K / X — когти (обои), L / C — мяу
- 1 / 2 / 3 — сменить кота, P — пауза
- На телефоне — экранные кнопки

Уровни: 1 — квартира (кухня, гостиная, спальня), 2 — дом с собакой Бубликом (прихожая, ванная, детская).

Вся игра — один файл `index.html`, без сборки и зависимостей.
